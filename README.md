# TontooMapsKit

Maps framework for TontooOS. Apple MapsKit-style API for TontooUI / UIKit apps:
an interactive 2D map view, place search with details, forward and reverse
geocoding, turn-by-turn routing and an optional 3D globe view.

## Made for TontooOS

Explore more at https://github.com/TontooOS/Libs

## Adding to Your Project

Add to your `Cargo.toml`:

```toml
[dependencies]
sdk = { path = "/Library/System/sdk", features = ["MapsKit"] }
```
